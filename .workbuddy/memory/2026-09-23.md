**踩坑 / 注意**
- `app.py` 的 `app.run(debug=True)` 带 reloader，做无头截图验证时用
  `-c "import app; app.run(port=5051, debug=False, use_reloader=False)"` 更稳。
- Bash 工具里用 `&` 启动的后台进程会在**该次命令结束时被一起杀掉** → 截图得到
  `ERR_CONNECTION_REFUSED`。必须用 Bash 的 `run_in_background: true`。
- Edge 无头截图的 `--screenshot=` 必须给**绝对路径**（`C:/.../x.png`），
  并加 `--user-data-dir` 指向临时目录，否则截图不落盘。
